# Vant 文档规范

## 定位

所有包以简体中文为默认语言。包名、命令、参数、路径、协议、字段、错误码、第三方产品名与许可原文保留必要英文。品牌统一使用 Vant，版权统一为 Copyright © 2026 Vant；第三方归属声明保持准确。

## 结构

| 文档 | 一级内容顺序 |
| --- | --- |
| README | 功能、环境要求、安装、快速开始、使用说明、开发与验证、文档、许可与版权 |
| Agent 规范 | 定位、调用流程、调用规范、结果验证、参考资料、许可与版权 |
| 命令参考 | 定位、调用方式、参数与输出、执行边界、结果验证、参考资料 |
| 配置与协议 | 定位、前置条件、字段与示例、执行边界、结果验证、参考资料 |
| 操作指南 | 定位、前置条件、操作流程、结果验证、参考资料 |
| 故障诊断 | 定位、问题与处理、结果验证、参考资料 |

## 内容

只描述当前版本的功能、约束和可执行流程。正文不保存研发过程、历史兼容方案、失效版本表或未经验证的成功结论。版本历史集中在 CHANGELOG。已实现的数据转换命令按当前功能说明，不将历史方案混入常规操作。

## 维护

修改生成器、插件清单与源文档后重新生成随包文档。示例使用占位符，不包含账号、密钥或具体业务数据。命令、字段、链接和打包内容应通过检查；模拟验证不能替代真实平台结果。
